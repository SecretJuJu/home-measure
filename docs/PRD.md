# HomeMeasure — PRD

## 1. Product Summary

HomeMeasure는 이사 전/입주 전 집 실측을 위한 iPad-first 웹 애플리케이션이다.

사용자는 현장에서 집 평면도를 간단히 그리고, 공간별 체크리스트를 따라 치수·문 열림 방향·창문·콘센트·수도·배수구·사진 등을 기록한다.

핵심 목표는 정교한 CAD 도구를 만드는 것이 아니라, **집을 떠나기 전에 필요한 실측 항목을 빠짐없이 수집하고 이후 가구·가전 구매 및 배치 판단에 활용할 수 있게 하는 것**이다.

---

## 2. Problem

기존 실측 방식은 다음 문제가 있다.

- 무엇을 측정해야 하는지 현장에서 빠뜨리기 쉽다.
- 사진을 많이 찍어도 어느 공간/항목의 사진인지 나중에 헷갈린다.
- 문 열림 방향, 경첩 위치, 콘센트/수도/배수구 위치 같은 비정형 정보가 흩어진다.
- 치수를 기록해도 가구/가전이 실제로 들어가는지 판단하기 어렵다.
- 집에 돌아온 뒤 다시 정리해야 한다.
- 중요한 치수를 빠뜨리면 재방문해야 한다.

---

## 3. Target User

### Primary
- 전·월세 계약 후 입주 전 실측하는 사용자
- 이사를 준비하는 사용자
- 가구/가전 구매 전 실측이 필요한 사용자

### Device
- Primary: iPad landscape
- Secondary: Desktop Web
- Mobile: 조회 및 간단 입력 정도만 지원

---

## 4. Product Principles

1. **Checklist-driven**
   - 사용자가 무엇을 재야 하는지 고민하지 않게 한다.

2. **Floor plan as context, not CAD**
   - 평면도는 정교한 설계가 아니라 실측 정보를 위치와 함께 저장하기 위한 인터페이스다.

3. **Spatial interaction first**
   - 문 방향 등을 텍스트 대신 시각적으로 선택한다.

4. **Capture in context**
   - 사진은 촬영 순간 특정 공간/항목과 연결된다.

5. **Missing information must be obvious**
   - 집에서 나오기 전에 미측정 항목을 한눈에 확인할 수 있어야 한다.

6. **Local-first**
   - 현장 네트워크가 불안정해도 입력을 잃지 않는다.

---

## 5. Core User Flow

```text
새 집 만들기
→ 집 유형 선택
→ 기본 공간 생성
→ 평면도 대략 작성
→ 실측 모드 시작
→ 공간 선택
→ 체크리스트 따라 측정
→ 사진/메모 연결
→ 미측정 항목 확인
→ 실측 완료
→ 요약 조회
```

## 6. Core Features

### P0 — MVP

#### Property
- 집 생성/수정/삭제
- 이름, 주소(선택), 메모

#### Room
- 공간 생성/삭제/이름 변경
- 공간 유형
  - 현관
  - 거실
  - 침실
  - 주방
  - 화장실
  - 베란다
  - 기타

#### Floor Plan
- 직사각형 공간 생성
- 벽 길이 입력
- 공간 위치 이동
- 문 배치
- 문 폭
- 경첩 위치
- 열리는 방향
- 창문 배치
- 콘센트/랜포트/수도/배수구/가스 등 아이콘 배치

#### Checklist
공간 유형에 따라 기본 체크리스트 자동 생성.

예:
- 현관문 폭/높이/열림 방향
- 베란다 출입문 폭
- 세탁기 공간 가로/깊이/높이
- 냉수/온수 여부
- 배수구 위치
- 냉장고 공간
- 콘센트 위치
- 창문 크기
- 천장 높이

기능:
- 완료/미완료
- 필수/권장 구분
- 직접 항목 추가
- 평면도 객체와 연결
- 측정값 입력 시 자동 완료

#### Measurement Mode
- 현장용 큰 UI
- 현재 측정 항목
- 숫자 입력
- mm 기본 단위
- 사진 촬영
- 메모
- 다음 항목 이동
- 모름/나중에

#### Photos
- 특정 Room 또는 Element에 연결
- 사진 촬영/업로드
- 메모
- R2 저장

#### Completion
- 전체 완료율
- 공간별 완료율
- 필수 미측정 항목
- 권장 미측정 항목
- 미측정 항목만 보기

#### Summary
- 방 치수
- 문 폭
- 세탁기 공간
- 냉장고 공간
- 최소 통과 폭
- 주요 설비 위치
- 사진

## 10. Success Criteria

MVP 기준:

- 사용자가 iPad 한 대로 집 전체 실측을 완료할 수 있다.
- 앱을 종료/새로고침해도 입력 내용이 보존된다.
- 네트워크가 끊겨도 측정 기록이 사라지지 않는다.
- 어떤 필수 항목을 빠뜨렸는지 집을 떠나기 전에 확인할 수 있다.
- 사진이 공간/측정 항목에 연결되어 이후 다시 이해할 수 있다.
- 평면도에서 문 열림 방향을 시각적으로 파악할 수 있다.

---

## 11. Product Definition

HomeMeasure는 “평면도 그리기 앱”이 아니다.

**집에서 나오기 전에 필요한 실측을 빠짐없이 끝내기 위한 앱**이다.

평면도, 체크리스트, 사진, 측정값은 모두 이 목적을 위한 수단이다.
